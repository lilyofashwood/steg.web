The static shelf already serves the local demos. These services add the dedicated Chatlog library origin, audio construction/deconstruction, or explicitly requested model calls. They do not start from this page. Melody uses its prepared Python environment. Do not put API keys in these commands or Git.

python3 chatlog-printer/scripts/serve-demo.py --port 8765
melody-cipher/.venv/bin/python melody-cipher/studio.py --port 8766
python3 steg-web/server.py --port 8768

Uniception still lives in the local steg-web folder, so its command has not changed. If a service link refuses the connection, its server is not running. A static workshop cannot make BYOK calls; open the corresponding dedicated link instead. The source links identify the corresponding GitHub repositories.

This shelf deliberately does not serve Markdown notes, archives, tests, background files, Python source, or Git internals. Use each repository’s GitHub link for its README and specifications. Existing in-demo documentation links may therefore return a deliberate 404 here.
